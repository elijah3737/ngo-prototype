API 610: что значит и как подобрать насос

Гайды· 5 минут чтения· обновлено 23.07.2026

API 610 — международный стандарт на центробежные насосы для нефтепереработки, нефтехимии и газовой промышленности. Если в спецификации указано «насос по API 610», это задаёт жёсткие требования к конструкции, материалам и испытаниям. Разберём, что стоит за стандартом и какие данные нужны для подбора.

Коротко

  • API 610 — стандарт на центробежные насосы для тяжёлых условий, гармонизирован с ISO 13709.
  • Три базовых типа исполнений: OH (консольные), BB (с опорой с двух сторон), VS (вертикальные погружные).
  • Для подбора нужны расход, напор, среда и её температура, давление и требования к уплотнениям.
  • Аналог подбирают в том же классе исполнения; для критичных позиций замену согласуют с проектировщиком.

API 610 — стандарт Американского нефтяного института на центробежные насосы для тяжёлых условий эксплуатации: высокие температуры, агрессивные и горючие среды, непрерывная работа. Действующая редакция гармонизирована с ISO 13709.

Что такое API 610

Стандарт регламентирует не «качество вообще», а конкретные вещи: тип корпуса и его прочность, систему уплотнений, конструкцию опор и подшипников, допустимые нагрузки на патрубки, материальное исполнение и обязательные заводские испытания.

Для заказчика это означает предсказуемость: насос, изготовленный по API 610, рассчитан на непрерывную работу в опасной среде и имеет подтверждённые характеристики.

Типы исполнений

OH (Overhung)консольные: рабочее колесо на консоли вала. Простые, распространённые, компактные.
BB (Between Bearings)вал опирается с двух сторон. Для высоких напоров и давлений, многоступенчатые исполнения.
VS (Vertical Suspended)вертикальные погружные. Для низкого подпора на всасывании и больших объёмов.

Внутри каждой группы есть подтипы (OH1, OH2, BB2, BB3 и так далее) — они различаются опорой корпуса, разъёмом и способом установки. В спецификации обычно указан конкретный подтип.

Параметры подбора

Насос подбирают по рабочей точке, а не по названию модели. Минимальный набор данных:

  • расход (производительность), м³/ч
  • напор, м, и рабочее давление
  • перекачиваемая среда, её плотность, вязкость и температура
  • давление на всасывании и доступный NPSH
  • требования к материальному исполнению и уплотнениям

Уплотнения и материалы

Торцевые уплотнения для насосов API 610 подбирают по сопряжённому стандарту API 682: он задаёт схемы уплотнений и вспомогательные системы (Plan 11, Plan 52, Plan 53 и другие). Ошибка на этом шаге — частая причина преждевременного выхода насоса из строя.

Материальное исполнение выбирают по среде: от углеродистой стали до дуплексных нержавеющих сталей для агрессивных и хлоридсодержащих сред.

Оригинал или аналог

Насосы по API 610 выпускают Grundfos, KSB, Sundyne и другие производители. При недоступности оригинала подбирают аналог того же класса исполнения с совместимыми присоединительными размерами и характеристиками в рабочей точке.

Для критичных позиций замену согласуют с проектной организацией: помимо гидравлики проверяют нагрузки на патрубки, схему уплотнения и требования по документации.

Что прислать для подбора

Быстрее всего работает опросный лист: в нём собраны все нужные поля. Если листа нет — достаточно рабочей точки, среды и маркировки существующего насоса или фото шильдика.

Частые вопросы

Что означает маркировка OH2 или BB3?
Это подтипы исполнений по API 610: OH2 — консольный насос на опорной раме с центральной опорой корпуса, BB3 — многоступенчатый с горизонтальным разъёмом корпуса. Подтип обычно указан в спецификации проекта.
Можно ли заменить насос API 610 обычным центробежным?
Как правило нет: стандарт задаёт требования к конструкции, испытаниям и документации, которые обычный насос общепромышленного исполнения не подтверждает. Замену следует согласовывать с проектировщиком.
Какие данные нужны, если опросного листа нет?
Расход, напор, среда и её температура, давление на всасывании, а также маркировка или фото шильдика существующего насоса. Этого достаточно для первичного подбора.
Поставляете ли вы ЗИП к насосам API 610?
Да: торцевые уплотнения, рабочие колёса, валы, подшипниковые узлы — по артикулу, чертежу или образцу. Работаем с оригиналом и проверенными аналогами.
